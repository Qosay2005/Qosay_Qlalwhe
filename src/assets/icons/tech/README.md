# Technology icons

Local SVGs are bundled by Vite; the section makes no external icon requests.

- `github.svg`: reused the `github-icon` symbol from the existing `public/icons.svg` sprite.
- `react-query.svg`: [Simple Icons React Query](https://cdn.simpleicons.org/reactquery/FF4154), from the [Simple Icons project](https://github.com/simple-icons/simple-icons) (CC0).
- `excel.svg`: [Office 365 icons](https://github.com/sempostma/office365-icons/blob/master/svg/excel.svg).
- Other SVGs: [Devicon](https://github.com/devicons/devicon/tree/master/icons) (MIT). SQL uses its Azure SQL Database symbol, a recognizable SQL cylinder.

Devicon source names: html5, css3, javascript, typescript, react, tailwindcss,
materialui, vitejs, npm (original-wordmark), git, postman, azuresqldatabase,
cplusplus, java, figma, canva, and notion. All use the `original` variant unless
otherwise noted.

Brand logos remain trademarks of their respective owners.
